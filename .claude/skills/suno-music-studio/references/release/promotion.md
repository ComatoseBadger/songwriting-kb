# Promotion: Copy, Platforms, Promo Video, Review

Use this to write and review release promo: the campaign plan, platform-specific social copy, promo video specs, and the review pass before posting. Pair it with `references/release/release.md` for timing and links.

> **Platform limits, algorithms and features change constantly.** The character limits, hashtag counts, video durations and posting windows here are a working snapshot. Re-check anything critical in each platform's current help pages before the user posts.

**User preferences win.** If the user has stated preferences, apply them everywhere and don't ask again. These include tone (casual, professional, hype, mysterious, storytelling), emoji level (none to heavy), point of view (first person "I made…", third person, or "we"), which platforms to cover or skip, themes to always or never mention, hashtags to always include or avoid, how to position AI, and the output language(s).

---

## 1. Workflow

1. **Gather material:** the album concept, track concepts, and the **streaming lyrics** (the clean, human-readable lyrics). **Never quote Suno-prompt lyrics.** They contain phonetic respellings, meta tags and cues that must never appear in public copy. If no clean lyrics exist yet, say that the hooks will be less specific and work from the track concepts.
2. **Write the campaign brief first.** Get the user's approval before writing any platform copy:
   - Overview: release name, date (or TBD), primary platform, campaign length
   - **Three key messages:** (1) the concept hook (what it's about), (2) the unique angle (what makes it different), (3) urgency or relevance (why listen now)
   - Target audience: 2–3 segments based on genre and themes
   - Schedule: pre-release, release week and post-release, with specific content types (see §5)
   - Hashtags: primary (discovery and genre) and secondary (release-specific, plus AI tags if relevant)
3. **Settle the language(s)** before drafting: English, another language, or bilingual (see §3).
4. **Settle the platforms:** all of them, or the user's chosen subset.
5. **Draft native copy for each platform** (§2–§4). Never cross-post identical text.
6. **Present each post with its metrics** (character count against the limit, hashtag count, status) and get approval or revisions before saving anything.
7. **Review pass** (§7), then replace the `[Streaming Link]` placeholders once the release is live.

### What to write per platform

| Platform | Deliverables |
|----------|--------------|
| Twitter/X | A release announcement (single tweet or thread), one promo tweet per track (hook, concept, link placeholder), one behind-the-scenes tweet, one engagement tweet (question or poll) |
| Instagram | A release caption (hook in the first 125 chars), 2–3 track-highlight captions with a story angle, one behind-the-scenes caption, and a separate hashtag block |
| TikTok | A release caption (under 150 chars), short casual captions per track, and one behind-the-scenes caption. The video carries the post |
| Facebook | A long-form release story (150–300 words), 2–3 track-highlight posts with a personal angle, and one behind-the-scenes story |
| YouTube | A description template (hook and links in the first 2–3 lines), a credits section, a links section, and 3–5 hashtags |

Format saved copy so it is easy to review one section at a time: a `##` heading per platform section, a `###` heading per post, and each post's copy in its own fenced code block. Leave character counts out of the saved file.

## 2. Copy Formulas

### Hook formulas (the first line has to stop the scroll)

| Hook | Templates | Best for |
|------|-----------|----------|
| **Question** | "What happens when [premise]?" / "Ever wonder what [subject] sounds like as [genre]?" / "What if [concept] had a soundtrack?" | Concept albums, thought-provoking themes |
| **Story** | "It started with [inciting incident]." / "In [year], [subject] did something no one expected." / "This track is about the moment when [turning point]." | Narrative or true-story tracks, threads, long captions, YouTube |
| **Contrast** | "[Genre A] meets [Genre B]. [Result]." / "The story of [dark topic], told through [unexpected genre]." / "[Beautiful thing] built on [ugly truth]." | Genre blends, light/dark contrast |
| **Number** | "[N] tracks. [N] true stories. One album." / "[N] months of research. Every lyric checked." | Announcements, tracklist reveals, documentary albums |
| **Quote** | "\"[Most quotable lyric]\"  Track [N] from [album], streaming now." | Lyric-driven tracks, ongoing promo, lyric cards |
| **Behind the scenes** | "This track almost didn't make the album. Here's why it did." / "I rewrote [track] [N] times before it felt right." | Post-release, authenticity, process-curious audiences |

### Calls to action, by goal
- **Drive streams:** "Listen now: [link]" · "Stream [album]: [link]" · "Full album on all platforms, link in bio." · "Out now on [platform]. Hit play."
- **Build audience:** "Follow for more from this album." · "More tracks dropping this week." · "What do you want to hear next?" · "Save this for when you need [mood]."
- **Drive engagement:** "Which track hits hardest? Drop your answer below." · "Tag someone who needs to hear this." · "What's your read on track [N]?" · "[emoji] if this resonates."

### Same message, native format
Core message: "[Album] is out, and it's about [concept]."
- **Twitter:** "[Album] is out now. [Concept in one sentence]. [N] tracks. Stream everywhere: [link] #NewMusic #Genre"
- **Instagram:** "[Album] is here." followed by 2–3 personal sentences on the story, then "Link in bio. Which track hits hardest?" and the hashtag block.
- **TikTok:** "new album just dropped. [concept in casual words]", plus a face-to-camera video with a snippet.
- **Facebook:** 3–5 paragraphs on why the user made it, the track highlights, "What do you think?" and the link.
- **YouTube:** "[Album] - [Artist] (Full Album)", the concept summary and link, then credits, tracklist and links.

### Turning album material into angles

| Album element | Copy angle |
|---------------|------------|
| Concept | "What if [premise]?" Pose the question the album answers |
| Track narratives | "Track 3 tells the story of…" Serialise the stories across posts |
| Lyrics | The single most quotable line as a standalone post or lyric card |
| Sonic palette | "We blended [genre] with [genre]…" for music nerds |
| Origin | "This album started when…" |
| Research | "Did you know [fact]?" for documentary albums |

### Content between releases
Don't post only when there is something to sell. Ideas: what you're listening to (share other artists), making-of shots (lyric drafts, revisions, settings), polls ("Art A or B?", "Which genre next?"), throwbacks with new context, resharing fans, honest (not inflammatory) takes on craft or genre, small milestones ("500 streams!"), a question of the day, lyric cards, and "did you know?" facts.

## 3. Platform Copy Rules and Limits

| Platform | Char limit | Visible before "more" | Hashtags (ideal / max) | Tone |
|----------|-----------|----------------------|------------------------|------|
| Twitter/X | 280 per post (paid accounts can post longer, but write to 280) | All | 1–2 / 5 | Punchy, conversational |
| Instagram | 2,200 | ~125 chars | 15–20 / 30 (posts fail above 30) | Visual storytelling, personal |
| TikTok | 4,000 (limits keep rising) | ~150 chars | 3–5 / 10 | Casual, unpolished, human |
| Facebook | ~63,206 | First 2–3 lines | 3–5 / 10 | Longer stories, community |
| YouTube description | 5,000 | First 2–3 lines | 3–5 / 15 (more is treated as spam) | Informative, organised, keyword-aware |

### Twitter/X
- URLs count as 23 characters. Emoji count as 2. Hashtags and @mentions count toward the 280.
- Threads: every tweet must stand alone under 280. Tweet 1 is the hook. Number the tweets (1/, 2/…). The last one carries the CTA and link.
- Never start a tweet with a hashtag. Put tags in the body. Rotate tag sets, because the same set every time looks like spam.
- Posts with outside links get suppressed. Lead with native media (audio snippet, video, image) and put the link in a reply or quote-tweet, or accept the reach hit on the release tweet itself.
- Write alt text for every image and video.

### Instagram
- Put the hook in the first 125 characters. Line breaks count as characters.
- Put hashtags in a separate block after the caption (dots or line breaks between). Mix about 5 high-volume tags (100K+ posts), about 10 mid-volume (10K–100K) and about 5 niche (under 10K). Rotate sets. Add location tags where relevant.
- CTAs: "Link in bio" (a link-aggregator page covers every store), "Save this", "Drop a [emoji] if this hits".

### TikTok
- Keep the caption under 150 characters. The video is the content, and text overlays matter more than the caption.
- Use 1–2 discovery tags (#NewMusic, #MusicTok, #IndieMusic), 1–2 genre tags and 1 trending tag if one fits. #fyp is debated, so use it sparingly if at all.
- Talk like a person, not a brand: "This part though." beats "Check out the bridge section of my new track."

### Facebook
- Put the hook in the first 2–3 lines. Longer, more personal posts outperform short promo.
- Use 3–5 hashtags at the end, for categorisation rather than discovery.
- End with a direct question to drive comments.

### YouTube
- Title: "[Track] - [Artist] (Official Audio)", or Lyric Video / Visualizer.
- Put the hook and streaming links above "Show more". Put keywords in the first 2 lines.
- The first 3 hashtags appear above the title. Use artist, album and genre.
- Pin a comment with the streaming links on every video.

### Hashtag recipes

| Phase | Twitter | Instagram | TikTok |
|-------|---------|-----------|--------|
| Pre-release | #NewMusic + genre | #NewMusic + genre + #ComingSoon | #NewMusic + #MusicTok |
| Release day | #NewMusic + genre | #OutNow + genre + niche mix | #NewMusic + genre + trending |
| Post-release | #NowPlaying + genre | Genre + mood + niche | #NowPlaying + genre |
| Evergreen | Genre only | Genre + mood + niche | Genre + trending |

Day-specific discovery tags: #MusicMonday on Mondays, #NewMusicFriday on Fridays. #IndieMusic works any day.

| Genre | Primary | Secondary |
|-------|---------|-----------|
| Hip-hop | #HipHop #Rap | #Bars #HipHopMusic #Underground |
| Electronic | #Electronic #ElectronicMusic | #Synth #Techno #DarkElectronic |
| Folk | #Folk #FolkMusic | #Acoustic #IndieFolk #Americana |
| Country | #Country #CountryMusic | #Americana #OutlawCountry |
| Rock | #Rock #RockMusic | #IndieRock #AltRock |
| Ambient | #Ambient #AmbientMusic | #Atmospheric #Drone |
| Dark cabaret | #DarkCabaret #Cabaret | #GothicMusic #Vaudeville |
| Industrial | #Industrial #IndustrialMusic | #EBM #DarkElectronic |

**Never use** #MusicPromotion or #SoundCloudPromotion (they attract bots), #FollowBack or #Like4Like (spam signals), or #MusicIsLife or #Beats (too generic to help discovery).

**AI tags** (#AIMusic, #SunoAI) go on a minority of posts, when the process is part of the story. Never tag a real artist's name to borrow their reach.

### Language and bilingual copy
- Write natively in each language. Adapt idioms and tone instead of translating templates word for word.
- **Bilingual format:** primary language first, then a `---` divider, then the secondary language, in the same post. Hashtags appear once, in English.
- **Twitter exception:** never stack two languages in one tweet. Use one tweet per language, or a two-tweet thread.
- Hashtags stay in English for international discovery.
- Quote lyrics in their original language, with a short translation in parentheses if the copy is in a different language. For example: *"Juste tourner, tourner"* (Just spinning, spinning).
- Internal notes and annotations stay in English.

## 4. Social Posting Best Practices

### What works per platform

| Platform | High-performing post types | Algorithm signals | Frequency (campaign / normal) | Typical windows (audience time zone) |
|----------|---------------------------|-------------------|-------------------------------|------------------------------|
| Twitter/X | Story threads, lyric quote cards, "how I made this" threads, polls, native audio or video snippets, quote-tweets with context | Replies and quote-tweets; native media beats links | 1–3 a day / 3–5 a week | 8–10 am, 12–1 pm, 5–7 pm |
| Instagram | Reels with an audio snippet (2–3× the reach of static posts), carousels (one track per slide), Stories with a link sticker, art reveal, lyric graphics | Saves and shares above likes; Reels go to Explore; carousels get a second showing | Feed 3–5 a week, Stories daily during a campaign | 11 am–1 pm, 7–9 pm |
| TikTok | "Listen to this part" clips, making-of, trends using your own audio, story time over music, duets and stitches with fan reactions | Completion rate and replays; the first 1–3 s decide everything | 1–3 a day / 4–7 a week (volume isn't penalised) | 7–9 am, 12–3 pm, 7–11 pm (timing matters less) |
| Facebook | Long-form story posts, native video, a release **Event** (sends automatic reminders), posts in genre groups, live streams | Comments and shares above reactions; live and video favoured; groups get more organic reach than Pages | 1–2 a day / 3–5 a week | 1–4 pm weekdays, 12–1 pm weekends |
| YouTube | Full track with visualizer, lyric video, Shorts (15–30 s hooks), track-by-track commentary, community posts | Watch time and thumbnail click-through; Shorts are ranked separately | 1–2 long-form a week + daily Shorts | n/a |

### Indie-artist tactics
- **Twitter:** build in public; pin the latest streaming link; post a track-by-track thread the week after release; reply to everyone during release week.
- **Instagram:** use Stories for raw content and the feed for polished posts; collaborate on Reels with similar artists; keep highlight collections ("New Album", "Process").
- **TikTok:** show your face (personality beats polish); put the hook in the first second; record 5–10 clips in one session; reply to comments with video; use trending formats with your own audio; make clips loop cleanly.
- **Facebook:** join genre groups and post there, not only on your own page; create a release Event; cross-post Instagram Reels.
- **YouTube:** keep thumbnails consistent; upload full tracks as "Official Audio" (they rank in search); build playlists by album, mood and genre.

### Release rollouts

**Single**
```
T-7  Teaser (IG Story, Twitter, TikTok)
T-3  Snippet / behind the scenes (all platforms)
T-0  Release announcement, staggered 1–2 h apart across platforms
T+1  Making-of
T+3  Lyric quote / fan engagement
T+7  "One week later" reflection or milestone
```

**Album**
```
T-14 Announcement + cover art reveal
T-10 Tracklist reveal (thread / carousel)
T-7  Lead single snippet + pre-save link
T-3  One track concept teaser a day
T-1  "Tomorrow" countdown
T-0  Release day, staggered across platforms over 4–6 h
T+1  Thank-you + early reactions
T+3  Deep-cut highlight
T+7  Track-by-track thread
T+14 Two-week reflection + stats
```

**EP:** T-7 announcement and art · T-3 lead-track snippet · T-0 release · T+3 behind the scenes · T+7 spotlight an underplayed track.

**Campaign arc:** Tease (T-14 to T-3: build anticipation without revealing everything) → Launch (T-0 to T+1: maximum energy and a clear CTA) → Sustain (T+2 to T+14: supporting content) → Evergreen (T+14 onward: lyric cards, milestones, throwbacks).

### Streams vs audience
- **Driving streams** (short term): direct links, "listen now" CTAs, snippets that make people want the full track, a release-day blitz.
- **Building an audience** (long term): process content, personality, replying to people and sharing fan posts, posting steadily between releases, teaching about the genre or the craft.
- Aim for about **70% audience-building and 30% stream-driving.** An audience compounds over time. Pushing streams without an audience gives diminishing returns.

### Talking about AI
- **Do:** lead with the story, concept and craft, and treat AI as an interesting detail rather than the headline. Present the user as the creative director ("I used AI tools to bring this concept to life"). Show the decisions they made: concept, lyrics, direction, curation, editing.
- **Don't:** lead with "AI-generated music", which invites dismissal before anyone listens. Don't apologise for it, put AI tags on every post, or get into "AI isn't real music" arguments.
- **When asked directly:** be honest and specific about which tools did what, and point to the human decisions. Never claim the user played or sang parts they didn't, and never suggest that a real artist was involved.

### Engagement habits
Reply to every comment in release week. Ask questions rather than making statements. Share other artists' work. Post consistently between releases. Use each platform natively. Show your face. Celebrate small wins. Make saveable content such as lyric cards and track breakdowns. Go live when you can. Be patient, because promotion compounds across releases.

## 5. Promo Video Specs

### Platform specs

| Platform | Aspect ratio | Max length | Sweet spot | Max file |
|----------|--------------|-----------|------------|----------|
| Instagram Reels | 9:16 | 90 s historically, now up to about 3 min (verify) | 15–30 s | 4 GB |
| TikTok | 9:16 only | Up to 10 min | 15–30 s | ~287 MB (mobile upload) |
| YouTube Shorts | 9:16 | Was 60 s, now up to about 3 min (verify) | 15–60 s | n/a |
| Twitter/X | 9:16, 16:9, 1:1 | 2:20 (140 s) on standard accounts | 15 s promos; up to 140 s for a sampler | 512 MB |
| Facebook | 9:16, 16:9, 1:1, 4:5 | Very long | 15–30 s | 4 GB |
| YouTube (long-form) | 16:9 | n/a | Full track | n/a |

### Universal delivery spec (works everywhere)
- 1080×1920 (9:16 vertical), H.264 (**not** H.265/HEVC), pixel format yuv420p, 30 fps
- AAC audio at 192 kbps, 44.1 kHz stereo, taken from the **mastered** file
- About 10–12 MB for 15 s. Keep files under 50 MB for Twitter and under 100 MB in general for easy upload
- Alternate shapes: 1080×1080 (1:1, often good in the Facebook feed), 1080×1350 (4:5), 1920×1080 (16:9 for YouTube)
- Make every video work muted: most social video is watched without sound, so add captions or text overlays

### Lengths and selection
- **Single-track promo:** 15 s by default. 30 s for a longer preview, 60 s rarely. Use the most energetic or recognisable 15 s, usually the chorus, hook or drop. If unsure, start about 20% into the track to skip the intro.
- **Album sampler:** one clip per track with short crossfades. Total = tracks × clip length − (tracks − 1) × crossfade. To fit Twitter's 140 s, each clip can be at most 140 ÷ number of tracks seconds (for example, 10 tracks × 12 s with 0.5 s crossfades = 115.5 s; 15 tracks need about 9 s each).
- **Which tracks where:** Instagram gets 2–3 standouts. Twitter gets the album sampler plus 1–2 key tracks. TikTok gets singles and the most energetic moments. Not every track needs a video, so don't flood the feed.

### Visual direction for audio-reactive visualizers
A common layout: the cover art (sharp, over a blurred copy of itself) in the top third, a waveform or spectrum in the middle, and the title and artist at the bottom in large white type with a drop shadow. Pick a waveform colour that complements the art, for example the hue opposite the art's dominant saturated colour.

| Style | Look | Fits |
|-------|------|------|
| Pulse | Centered oscilloscope with heavy glow | Electronic, hip-hop, EDM |
| Bars | Fast spectrum bars, classic visualizer | Pop, rock, metal |
| Line | Clean, minimal waveform | Acoustic, folk, jazz, classical, country |
| Mirror | Symmetric waveform with soft glow | Ambient, chill, downtempo |
| Mountains | Mirrored spectrum, cinematic | EDM, bass-heavy, cinematic |
| Colorwave | Clean waveform with subtle glow | Indie, alternative, dream pop |
| Neon | Sharp, bright glow | Synthwave, 80s, high-energy electronic |
| Dual | Two contrasting waveforms | Experimental |
| Circular | Vectorscope or Lissajous pattern | Abstract, IDM, glitch |

Platform leanings: Instagram and TikTok favour high-energy styles (pulse, bars, neon). Avoid the most abstract and the most minimal styles there. Twitter favours clean, readable styles (pulse, colorwave) because previews are small. Tempo guide: 140+ BPM suits bars, neon or pulse. 90–140 BPM suits pulse, colorwave or line. Under 90 BPM suits mirror, mountains or line.

Other formats worth suggesting: lyric videos for YouTube, a Spotify Canvas loop (3–8 s vertical), face-to-camera "listen to this part" clips for TikTok, and still images with a waveform for the cheapest option.

### Video QA and upload checklist
- [ ] 9:16, 1080×1920 (or the intended alternate shape), H.264 + yuv420p, 30 fps, AAC
- [ ] The intended duration, within the platform limit, and the file under the size limit
- [ ] Audio comes from the master, is in sync, and has no clipping or glitches
- [ ] The visualizer clearly reacts to the audio, and its colours suit the art
- [ ] The artwork is visible and sharp, not covered by the waveform
- [ ] The title and artist are spelled correctly and readable **on a phone**. Always test one video on a phone before making the full batch
- [ ] The first frame makes a strong thumbnail (it autoplays muted). Short clips loop smoothly
- [ ] Captions or text overlays are present, and alt text is written. For example: "Animated waveform for 'Title' by Artist. Glowing orange line over blurred blue cover art. Title and artist at the bottom."
- [ ] Caption copy, hashtags and the streaming link are ready
- [ ] For YouTube Shorts, add #Shorts in the title or description

## 6. Promo Review Checklist

Review **one post at a time.** For each post, show the copy with its metrics: character count against the platform limit, hashtag count, line count, and pass/fail status. Split threads into individual tweets and count each one separately. Never approve on the user's behalf.

### Revision actions to offer
- **Approve:** keep as is.
- **Revise:** rewrite from the user's feedback.
- **Shorten:** cut filler ("really", "very", "just"), merge sentences, lead with the strongest element, and get under the limit.
- **Punch up:** stronger verbs, curiosity or urgency, a hook instead of a description. Keep the core message.
- **Hashtags:** suggest 3–5 options that fit the genre and themes, within the platform's maximum. The user chooses.
- **Retone:** ask for the target tone first (casual, professional, hype, mysterious, storytelling, urgent), then change only the voice, not the facts.
- **Strengthen messaging** (campaign brief only): make the key messages tighter and more quotable, make the schedule entries specific and actionable, and check they match the album's themes. The campaign brief has no character limits.
- **Skip.**

After each revision, show the new version with updated metrics and offer: approve, revise again, or revert. Save only the posts that changed. Between platforms, keep a running tally of approved, revised, skipped and over-limit posts.

### Per-post checks
- [ ] Within the platform's character limit (Twitter counts URLs as 23 and emoji as 2)
- [ ] Hook in the visible preview (125 chars on Instagram, 150 on TikTok, first 2–3 lines on Facebook and YouTube)
- [ ] Hashtag count in the ideal range and below the maximum. No banned tags. No tweet starts with a hashtag
- [ ] A clear CTA ("Listen now", "Stream", "Link in bio", or a question)
- [ ] A streaming link or "link in bio" on every release post
- [ ] Album and artist names present and spelled correctly
- [ ] Specific to this release, not generic copy that could promote anything
- [ ] Written for this platform, not cross-posted text
- [ ] Quotes come only from the clean streaming lyrics, with no phonetic respellings or meta tags
- [ ] AI is framed according to the user's preference and §4, with no implied real-artist involvement
- [ ] Matches the user's preferred tone, POV and emoji level, and stays within their "never mention" list
- [ ] **Placeholders flagged:** `[Album Name]`, `[Streaming Link]`, `[Genre]`, `[Date]`, `[Post copy]`

### Common fixes
Over the limit: shorten, or split into a thread on Twitter. Too few hashtags: add some, especially on Instagram. Too many: trim to the ideal range. No CTA: add one. No link: add the link or "link in bio". Generic: swap in a concrete detail, lyric or story beat from this release.
