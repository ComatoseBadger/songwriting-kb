# Pronunciation for Suno Lyrics

Suno guesses pronunciation from spelling. A wrong guess ruins the take and wastes a generation. Scan every vocal lyric for risky words, respell them in the **Suno Lyrics Box only**, and keep standard spelling in the published/streaming lyric sheet.

Skip this entirely for instrumental tracks.

---

## Why It Matters

- Suno reads lyrics literally and its context sensitivity is limited. **Never trust context for homographs** — always respell.
- **IPA is not supported.** Use plain phonetic respelling.
- Example: "LiveJournal confessions" was sung "LIV-journal" (like a live show) instead of "LYVE-journal".

---

### 3. Acronyms and Initialisms

**Rule:** letter-by-letter acronyms get spelled out with hyphens or periods (`F-B-I` or `F.B.I.`); periods most strongly force letter-by-letter (`S.L.S.`, `L.K.M.L.`, `B.D.F.L.`, `D.F.S.G.`, `A.P.I.`). Without separators Suno may try to say them as a word. Word-like acronyms get a phonetic respelling. A fully phonetic form also works: `A.P.I.` → `ay pee eye`.

| Letter-by-letter | Write as |
|---|---|
| FBI, CIA, NSA | `F-B-I`, `C-I-A`, `N-S-A` |
| API, CLI, SSH, DNS, VPN | `A-P-I`, `C-L-I`, `S-S-H`, `D-N-S`, `V-P-N` |

### 5. Numbers

Spell numbers out — Suno handles words more reliably than digits.

| Written | Suno might say | Write |
|---|---|---|
| 1993 | "one nine nine three" | `nineteen ninety-three` or `'93` |
| 2024 | "two zero two four" | `twenty twenty-four` |
| 1984 | | `nineteen eighty-four` |
| 21 / 63 / 300 | "six three" | `twenty-one` / `sixty-three` / `three hundred` |

## Fix Methods (in priority order)

1. **Rewrite** — avoid the word. "LiveJournal confessions" → "Old blog confessions"; "I read your message yesterday" → "I saw your message yesterday".
2. **Phonetic respelling** — looks odd, works: `red`, `led`, `wownd`, `lyve`, `liv`, `Life-journal`.
3. **Hyphenation** — break syllables to force a vowel: `li-ive` (long i), `ree-ead` (long e), `wi-ind` (long i). Also guides syllable count and sustained notes.
4. **Context padding** — make the reading obvious: "Live broadcast from the scene" → "Broadcasting live from the scene"; "The lead singer" → "Leading the band".
5. **Accept it** — if the wrong reading is not jarring, document the risk in the production notes and move on.

### Respelling Conventions

- Hyphens mark syllable breaks: `Sin-ah-lo-ah`.
- Capitals mark stress when ambiguous: `reh-CORD` (verb) vs `REH-cord` (noun); capitalising one syllable to force stress (`re-COR-ded`) is reported to work. Use it sparingly — it is a scalpel, and ALL CAPS on whole words reads as shouting.
- Spell brand names and acronyms as sounds.

## Languages and Accents

### Multilingual Tracks

- **One language per section** — mixing within a section causes pronunciation drift.
- Add `all lyrics in [language], no English` to the Style Box for non-English songs to stop the model reverting to English; for mixed songs state both: `bilingual, Spanish verse, English chorus`.
- Label sections: `[Verse 1 - Spanish]`, `[Chorus - English]`.
- **Korean**: romanized with hyphens is more reliable than Hangul (`Sa-rang-hae`); add `[Clear Vocals]` when code-switching.

### German

Suno applies English phonetics to German vowels.

- **Long vowels**: a single final vowel that should be long gets read short — double it: `juchhe` → `juchee`. (`Schnee`, `See` already doubled, usually fine.)
- **Umlauts** are inconsistent — test; if wrong, `ä`→`ae`, `ö`→`oe`, `ü`→`ue`. `ß` usually reads as "ss" (fine).
- Interjections: `juchhe` → `juchee`; `juhu`, `hurra`, `ach`, `oho` usually fine.

### Accent Simulation

No direct accent control. Respell the lyrics as spoken in the accent (not dictionary spelling) and add the accent to the Style Box (`Russian accent`, `Jamaican accent`, `Southern drawl`).

| Standard | Russian | Jamaican | Southern US |
|---|---|---|---|
| I'm going to the store | Ahm go-ink to da store | Mi ah go ah di store | Ahm goin' to tha store |

Simple accents (Russian, Irish) work better than complex regional dialects.

## Scan and Enforcement Workflow

### 1. Scan

Read every line. Flag with these patterns plus judgment:

```
\blive\b  \bread\b  \blead\b  \bwind\b  \bclose\b  \btear\b  \bbass\b  \bwound\b  \bbow\b   (homographs)
\bSQL\b  \bLinux\b                                                                (tech terms)
[A-Z]{2,5}                                                                        (potential acronyms)
\d{4}                                                                             (years)
\d{2,3}                                                                           (numbers)
```

Also scan for: non-English names and places, brand names, regional-variant words, and (if a Style Box exists) any artist names.

### 2. Decide

| Auto-fix | Ask the user first |
|---|---|
| Tech terms (SQL → S-Q-L, Linux → Lin-ucks) | Homographs (live, read, lead, wind, tear…) |
| Common acronyms (FBI → F-B-I, GPS → G-P-S) | Names (confirm preferred pronunciation) |
| Numbers (1993 → nineteen ninety-three / '93) | Regional variants (data, either, route) |

When in doubt, ask — clarifying is cheaper than regenerating. Test: say the line both ways and ask "if Suno picks wrong, is the song ruined?" If yes, fix it.

### 3. Report

```
PRONUNCIATION RISKS FOUND (3):

Line V1:3 -> "We live in darknet spaces"
  Risk: "live" is a homograph
  Options: "lyve" (verb) or "liv" (adjective)
  -> Needs clarification

Line C:1 -> "SQL injection in the code"
  Risk: tech acronym
  Fix: "S-Q-L" or "sequel"
  -> Auto-fix: "S-Q-L injection in the code"

Line V2:5 -> "Reading Linux logs at 3AM"
  Risk: commonly mispronounced
  Fix: "Lin-ucks"
  -> Auto-fix: "Reading Lin-ucks logs at three A-M"
```

Summary form:

```
PRONUNCIATION SCAN COMPLETE
Risks found: X   Auto-fixed: Y   Needs user input: Z

FIXES APPLIED:
- "SQL" -> "S-Q-L" (V1:3)
- "Linux" -> "Lin-ucks" (V2:5)

NEEDS USER INPUT:
- "live" (C:1) - lyve or liv?

CLEAN LYRICS:
[full Suno lyrics with all fixes applied]
```

### 4. Keep a Pronunciation Table

Record every decision per song:

| Word/phrase | Phonetic | Notes |
|---|---|---|
| Jose Diaz | Ho-zay Dee-ahz | Spanish name |
| live | lyve | verb (to reside) |
| SQL | S-Q-L | spell out |

Keep a running **project-level list** too, grouped as: artist names, album/track titles, character names, location names, genre jargon. Reuse it on every song in the project; the user's entries win over the general tables above.

### 5. Enforce

The table is a mandatory checklist, not documentation. As the **last step before generation**, after all other edits:

1. Read the table top to bottom.
2. For each entry, search the Suno Lyrics Box for the standard spelling.
3. Replace with the phonetic version.
4. Verify **every occurrence** — verses, choruses, bridges, outros. The common failure is a word added to the table but never applied, or fixed in one verse and missed in the chorus.
5. When adding a new word to the table later, apply it to all Suno lyrics immediately.

```
| Word  | Standard | Phonetic | Applied?             |
|-------|----------|----------|----------------------|
| Ramos | Ramos    | Rah-mohs | yes, all 4 occurrences |
| live  | live     | lyve     | yes, V1, V2, Chorus  |
| FBI   | FBI      | F-B-I    | yes, Bridge          |
```

Streaming/distributor lyrics always keep standard English spelling.

### Fixing After Generation

If one word comes out wrong in an otherwise good take, use Replace Section with identical lyrics and only the problem word respelled — the surrounding audio stays intact ([models-and-sliders.md § Replace Section](models-and-sliders.md#replace-section-propremier)).
